# EVOC KODE

Landing website for EVOC KODE, a custom mobile app development studio. It covers the full journey from first call to App Store and Google Play launch.

Built with Next.js 16 (App Router), React 19 and JavaScript.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
```

## Production

```bash
npm run build
npm start
```

## Editing content

All copy, contact details and testimonials live in `lib/site.js`.
